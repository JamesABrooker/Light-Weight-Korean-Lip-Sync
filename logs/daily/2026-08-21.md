## 2026-08-21: KMSAV pilot clip selection

Built a candidate pool from `data/list.txt` (5,259 videos total) before selecting 
the pilot subset:

- Filtered to `train`/`valid`/`test` splits only (515 videos), excluding `pretrain` 
  (4,744 videos) since pretrain data isn't intended for labeled/transcript-reliant 
  use the way train/valid/test are.
- Filtered to ≤3 participants per video. Some entries have 100+ "participants" 
  (crowd/reaction-style content) which active-speaker detection handles poorly - 
  excluding these avoids garbage crops down the line.
- Filtered to 60-3600s video length to avoid extreme outliers.
- Result: 295 candidates (276 train / 11 test / 8 valid).

From the 295, stratified-sampled 35 source videos for the pilot (train split only, 
capped at 8 per domain to avoid `issu` [issue/debate content] dominating the sample), 
totaling ~10 hours of source video. Expect this to yield 500+ usable utterance-level 
clips after ASD-based cropping and the 2-10s length filter (per issue acceptance 
criteria), with headroom to be selective about quality.

Candidate list: `data/kmsav_pilot_candidates.csv`. Random seed fixed (42) for 
reproducibility if selection needs to be regenerated.

Next: download + crop pilot videos locally (`run_pilot_pipeline.sh`), build final 
manifest from actual cropped utterance output.
