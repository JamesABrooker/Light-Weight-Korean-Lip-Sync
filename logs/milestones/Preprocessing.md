## Preprocessing

This section records exactly how the raw data was turned into Wav2Lip's training/evaluation format,
and every place where this project deviates from the original Wav2Lip pipeline. Daily notes with the
reasoning behind each decision are in [`logs/daily/`](logs/daily/).

### Overview

| Stage | Script | Output |
|---|---|---|
| 1. Download + face-track cropping (KMSAV) | [`run_pilot_pipeline.sh`](run_pilot_pipeline.sh) | `kmsav_pilot/cropped/<video_id>/utts/<utt>.mp4` + `.wav` |
| 2. Manifest + manual clip review | [`build_manifest.py`](build_manifest.py), [`scripts/manual_data_check.py`](scripts/manual_data_check.py) | `data/kmsav_pilot_manifest_reviewed.csv` |
| 3. Frame-rate checks | [`scripts/check_fps.sh`](scripts/check_fps.sh), [`scripts/verify_fps.sh`](scripts/verify_fps.sh) | — |
| 4. Audio extraction + mel verification | [`scripts/audio_preprocessing.py`](scripts/audio_preprocessing.py), [`tests/`](tests/) | `data/kmsav_processed/`, `data/lrs3_eval_processed/` |
| 5. Wav2Lip dataset layout + splits | [`scripts/build_wav2lip_dataset.py`](scripts/build_wav2lip_dataset.py) | `data/kmsav_wav2lip/`, [`filelists/kmsav/`](filelists/kmsav/), `logs/build_kmsav_*.csv` |
| 6. English evaluation subset | [`scripts/fetch_lrs3_eval.py`](scripts/fetch_lrs3_eval.py) | `data/lrs3_eval/`, [`data/lrs3_eval_ids.txt`](data/lrs3_eval_ids.txt) |

Data directories (`data/kmsav_*`, `data/lrs3*`) are git-ignored and not redistributed; see the dataset
licence notes above. Scripts, filelists, clip ID lists and build logs are committed so every step can
be re-run.

### Dataset selection

- **Korean (training + evaluation): KMSAV.** OLKAVS was the original plan but requires Korean
  nationality for access. KMSAV is CC-BY-NC-SA 4.0 and provides face-track metadata.
- **Subset:** 772 manually reviewed utterance clips from 29 videos (29 speakers). The proposal
  planned ~500; all reviewed clips were kept, since more data helps fine-tuning.
- **English (evaluation only): LRS3-TED,** a fixed 100-clip subset of trainval (first clip from each
  of the first 100 videos in the archive, i.e. 100 different speakers). Wav2Lip was trained on LRS2 and
  never saw LRS3, so this is a fair held-out set. Used only to measure whether Korean fine-tuning
  degrades English lip-sync.

### Frame rate

All data is at **25 fps**, Wav2Lip's training frame rate.

- KMSAV source videos are 29.97 fps; the cropped clips are output at 25 fps by the cropping pipeline.
- LRS3 clips are natively 25 fps (224×224 face tracks).
- 25 fps is required, not just a default: the frozen SyncNet expert pairs Tv = 5 video frames with
  16 mel steps (80 mel frames/s), i.e. 0.2 s of audio. That alignment only holds at 25 fps. The
  `syncnet_python` evaluation also re-encodes to 25 fps.

### Cropping

- KMSAV's own face-track bounding boxes are used to crop faces, instead of running Wav2Lip's S3FD
  face detector. Bounding boxes were verified manually against the footage.
- Bounding-box metadata is matched to the resolution of the video actually downloaded, not the
  resolution listed in the metadata (several videos downloaded at a different resolution, which
  initially produced wrong crops).
- Crops are 224×224 face tracks. Wav2Lip's dataloader resizes them to 96×96 at load time, as with LRS2.
- Clips whose face track starts on a non-face shot or scene change were removed during manual review.

### Audio processing

Implemented in [`scripts/audio_preprocessing.py`](scripts/audio_preprocessing.py). It reproduces
Wav2Lip's `audio.py` + `hparams.py` exactly:

| Parameter | Value |
|---|---|
| Sample rate | 16 kHz, mono |
| Mel bands | 80 |
| n_fft / hop / win | 800 / 200 / 800 (80 mel frames per second) |
| fmin / fmax | 55 / 7600 Hz |
| Pre-emphasis | 0.97 |
| min_level_db / ref_level_db | -100 / 20 |
| Normalization | symmetric, clipped to [-4, 4] (`symmetric_mels=True`, `max_abs_value=4`) |

- KMSAV stores each utterance's audio as a separate 16 kHz mono `.wav` next to a silent `.mp4`;
  the `.wav` is used directly.
- Audio inside video containers (LRS3) is decoded with ffmpeg, as in Wav2Lip's own preprocessing.
- **Verification:** [`tests/test_audio_pipeline.py`](tests/) checks that our mels match golden mels
  generated by Wav2Lip's own `audio.py` (in a librosa 0.9.2 environment, via
  [`tests/make_golden.py`](tests/make_golden.py)) to within 1e-4, on one Korean and one English clip.
  A side-by-side spot-check is in [`docs/audio/spotcheck_english.png`](docs/audio/spotcheck_english.png).
- Results: KMSAV 772/772 and LRS3 100/100 processed, 0 failures.

Note: Wav2Lip's training code computes mels itself from `audio.wav`. The parity tests are what
guarantee those mels match what the frozen SyncNet expert was trained on.

### Wav2Lip dataset layout and splits

[`scripts/build_wav2lip_dataset.py`](scripts/build_wav2lip_dataset.py) writes the structure Wav2Lip's
dataloader expects:

```
data/kmsav_wav2lip/<video_id>/<utt_id>/0.jpg, 1.jpg, ..., audio.wav
filelists/kmsav/{train,val,test}.txt      # one "<video_id>/<utt_id>" per line
```

- Per clip, it checks: 25 fps video, 16 kHz mono audio, at least 15 frames, and frame count within
  ±2 frames of audio duration × 25. Every clip is logged with status and reason in
  `logs/build_kmsav_<timestamp>.csv`. Result: 772/772 ok.
- **Split:** speaker-disjoint (grouped by `video_id`), targeting ~78/7/15% of clips. Seed 103 was
  chosen by simulating 200 seeds on split sizes only, before any evaluation was run:
  **597 train / 59 val / 116 test clips.**
- **Alignment check:** clip `54ULzusB3zU/000010` was remuxed from its frames and `audio.wav`
  (246 frames = 9.84 s, matching the audio exactly) and confirmed in sync by eye.
- Wav2Lip reads `filelists/{split}.txt` relative to its working directory, so copy or symlink
  `filelists/kmsav/*.txt` into `external/Wav2Lip/filelists/` before training.

### Deviations from the original Wav2Lip pipeline

| # | Original Wav2Lip | This project | Why |
|---|---|---|---|
| 1 | Trained and evaluated on LRS2 | KMSAV (Korean) for fine-tuning and evaluation | Research question is Korean lip-sync |
| 2 | English evaluation on LRS2 test set | Fixed 100-clip LRS3 subset | LRS2 needs a BBC institutional licence, not obtainable in time. Absolute LSE scores are therefore not directly comparable to the paper's LRS2 numbers; before/after comparisons on the same clips remain valid |
| 3 | S3FD face detection per frame (`preprocess.py`) | KMSAV face-track bounding boxes | Metadata is accurate and avoids re-running detection. Crop framing (e.g. chin padding) may differ slightly from S3FD crops |
| 4 | Source video already 25 fps | KMSAV converted from 29.97 to 25 fps | Required for the frozen expert's 5-frame / 0.2 s window |
| 5 | Paper's benchmark: ~14K randomly paired audio-video samples | Own speaker-disjoint split of 772 clips | Subset size chosen for feasibility on one GPU |
| 6 | Audio extracted from video with ffmpeg | KMSAV's separate per-utterance `.wav` files | That is how KMSAV distributes audio. Mel recipe itself is unchanged and parity-tested |

Deviations from the original **proposal**: OLKAVS → KMSAV (access), LRS2 → LRS3 (licence), planned
change of Wav2Lip to 30 fps dropped (KMSAV clips are 25 fps, and 30 fps would misalign the frozen
expert), ~500 → 772 clips.

### Reproducing

```bash
# from wav2lip-korean/
python scripts/audio_preprocessing.py verify
python scripts/audio_preprocessing.py manifest data/kmsav_pilot_manifest_reviewed.csv \
    --out-dir data/kmsav_processed --clip-root .
python scripts/fetch_lrs3_eval.py --n 100            # needs `hf auth login`
python scripts/audio_preprocessing.py batch data/lrs3_eval --out-dir data/lrs3_eval_processed
python scripts/build_wav2lip_dataset.py data/kmsav_pilot_manifest_reviewed.csv \
    --test-frac 0.15 --val-frac 0.07 --seed 103
pytest tests/ -v
```
